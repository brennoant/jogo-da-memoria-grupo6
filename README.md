# Jogo da Memória

Aplicativo desenvolvido como trabalho final da disciplina de Desenvolvimento de Aplicativos Móveis. O jogo permite que o usuário escolha tema e dificuldade, jogue partidas de memória e acompanhe seu desempenho em um ranking local. Administradores podem cadastrar novas cartas via Firebase Firestore.

## Tecnologias e Arquitetura
- **Linguagem:** Kotlin
- **UI:** Jetpack Compose
- **Arquitetura:** MVVM (Model-View-ViewModel)
- **Banco Local:** Room 3 (androidx.room3)
- **Navegação:** Navigation Compose
- **Backend:** Firebase Firestore
- **Padrões:** StateFlow + UiState, Factory Pattern, Repository Pattern
